# Pinning and favorites

Allow users to pin items so they always appear at the top of the
result list, or mark favorites that surface prominently in the empty
query state.

## Considerations

- Pin to top of global list, or per-plugin pinning?
- Visible pin indicator in the result row?
- Keyboard shortcut to pin/unpin from the action palette?
- Storage: settings store or separate data file?
- Interaction with frecency ranking — do pinned items override
  learned rankings entirely?

## Status

Deferred — not essential for initial implementation. Can be added
later without architectural impact.
